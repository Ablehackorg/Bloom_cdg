# 🐝 Bloom

**Bloom** — это современная краудфандинговая веб-платформа, вдохновлённая  
🌍 **Целями устойчивого развития ООН (SDG — Sustainable Development Goals)**.  

Мы боремся с глобальными вызовами: **бедность, неравенство, доступ к образованию, экология**.  
Наша цель — объединить людей, идеи и ресурсы для создания устойчивого будущего.  

---

## 🎯 Mission & Vision

- 🔗 Соединять людей и организации, поддерживающих важные инициативы  
- 🌱 Поддерживать проекты, которые решают реальные социальные и экологические задачи  
- 📈 Создавать устойчивые сообщества и инфраструктуру  
- ✨ Делать вклад в достижение целей **SDG ООН** на глобальном уровне  

---

## 💎 Values

- **Прозрачность** — каждый проект и вклад открыты для сообщества  
- **Влияние** — поддерживаем инициативы с измеримым результатом  
- **Равенство** — участие доступно каждому  
- **Устойчивость** — создаём долгосрочные решения, а не временные меры  

---

## 🛠️ Tech Stack

- **Backend:** Django / Django Rest Framework  
- **Frontend:** React + Vite + TypeScript  
- **UI/UX:** TailwindCSS, shadcn/ui, Lucide Icons  
- **Database:** PostgreSQL  
- **Cache / Queue:** Redis + Celery  
- **DevOps:** Docker, GitHub Actions, Nginx
